# Address Book

A command-line Address Book application developed in **C** for managing contact information.

## Features

* Add a new contact
* Search for a contact
* Edit existing contact details
* Delete a contact
* Display all contacts
* Store and manage contact information using file handling

## Technologies Used

* **Language:** C
* **Compiler:** GCC
* **Platform:** Linux / Windows
* **Concepts:** Structures, Functions, Pointers, Arrays, File Handling

## How to Compile

Using GCC:

```bash
gcc *.c -o addressbook
```

## How to Run

### Linux / Git Bash

```bash
./addressbook
```

### Windows

```bash
addressbook.exe
```
